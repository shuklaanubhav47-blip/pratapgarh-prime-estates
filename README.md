# Pratapgarh Prime Estates - 360° Real Estate Platform

A modern, mobile-first real estate website for luxury villas in Pratapgarh with immersive 360° view.

**🔗 Live Demo:** https://YOUR-USERNAME.github.io/pratapgarh-prime-estates/
**📍 Location Focus:** Katra, Bela, Pratapgarh (UP)

### Features
- 360° Drag to Rotate Viewer (Touch + Mouse support)
- 100+ Dynamic Property Cards
- Wishlist System with LocalStorage
- Client Feedback & Star Rating
- EMI Calculator with Registry Calculation
- Light/Dark Mode + 12 Language Support
- Fully Responsive

### Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- LocalStorage for Wishlist & Feedback
- YouTube Embeds for Video Tours

### How to Run
1. Download `index.html`
2. Open in Chrome
3. No server needed

### What I Learned
- Touch events (touchstart, touchmove) for mobile
- Building custom 360° viewer without library
- LocalStorage handling
